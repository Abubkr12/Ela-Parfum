# Design System & UI/UX Guidelines — Ela Parfum

## Design System Tokens
- **Tema Visual:** Luxury Perfumery & Modern Utilitarian
- **Warna Utama:** Emerald Luxury (`#064e3b`), Gold Amber (`#d97706`), Neutral Slate (`#0f172a`), Clean Pearl (`#f8fafc`)
- **Tipografi:** Sans-serif modern, hierarchy tajam tanpa teks dekoratif berlebihan
- **Komponen UI:** Custom Bento Grids, Toast notifications via Sonner, Responsive Drawers, Zero Stock Emoji (gunakan Lucide React icons)
- **Animasi:** Micro-interactions halus dengan Framer Motion, transition cubic-bezier terukur tanpa jank
